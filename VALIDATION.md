# Two-objective network-design validation (2026-10-29)

The model follows the [two-objective specification](docs/sample_problem.md) and minimizes expected annual cost and expected disruption unmet demand. CO₂ has been removed from model expressions, inputs, normalization, weights, epsilon bounds, nondominance, reports, dashboard charts and generated media. Schema-v2 data preserves the previous non-emission input values, and results explicitly identify their two objective keys so old results cannot be loaded as the new model.

Local environment: Python 3.9.6, Pyomo 6.9.5, HiGHS/highspy 1.15.1 on macOS arm64. Exact dependencies are recorded in [requirements-lock.txt](requirements-lock.txt). Python 3.11 is configured in GitHub Actions; remote CI was not run in this session.

The CLI preliminary feasibility solve is additional to that count. It returned **19 optimal-within-tolerance terminations**, **9 time limits**, and **0 infeasible attempts**. The [saved demonstration](examples/network_design/README.md) contains **21 unique nondominated cost/shortfall vectors**. All **28** feasible records passed an independent audit. Nonzero anchor gaps are retained, and normalization values are labeled as incumbent estimates. The sampled frontier does not certify completeness or global Pareto optimality.

The default MILP still has 408 binary variables, 4,260 continuous variables and 4,926 constraints before epsilon bounds. Normal demand is fully served. The hand-checkable design opening both warehouses and all links has cost 56 and expected unmet demand 0; its cost-only optimum has cost 27 and expected unmet demand 3.
